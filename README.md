# Study02_testA

하루 10~20개 정도의 할 일을 관리하는 개인용 할 일 관리 앱(Todo App)입니다.
순수 HTML / CSS / JavaScript로 만들었고, 서버나 빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- 할 일 추가 / 수정(더블클릭 또는 ✎ 버튼) / 삭제
- 완료 체크 (완료 항목은 취소선 처리 후 목록 아래로 이동)
- 카테고리 분류 (업무 / 개인 / 공부)와 필터 탭
- 진행률 보기 (전체 + 카테고리별)
- `localStorage`에 자동 저장되어 새로고침해도 데이터 유지

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

> 데이터는 사용 중인 브라우저의 `localStorage`에 저장됩니다. 브라우저 사이트 데이터를 삭제하면 사라지고, 다른 브라우저나 기기와는 공유되지 않습니다. 시크릿 모드 등 저장소를 쓸 수 없는 환경에서는 화면에 경고가 표시됩니다.

## 파일 구조

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 마크업 |
| `style.css` | 스타일 (반응형, 다크 모드 지원) |
| `app.js` | 로직 (Storage / State / Selectors / Render / Events) |
| `PRD.md` | 제품 요구사항 문서 |
| `PROMPTS.md` | PRD 기반 Claude Code 단계별 구현 프롬프트 |
